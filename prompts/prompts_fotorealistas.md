## NOTAS TÉCNICAS PARA MIDJOURNEY v6.1 E FLUX.1

| Parâmetro | Recomendação |
|-----------|--------------|
| **--ar** | 16:9 para hero/bastidores, 4:5 para retratos e cards, 1:1 para detalhes e Instagram |
| **--style raw** | Sempre usar para fotorealismo máximo e menos "artificial" look |
| **--v 6.1** | Versão mais fotorealista do Midjourney |
| **--s (stylize)** | Manter entre 100-200 para não perder o realismo |
| **--q (quality)** | Sempre --q 2 para máximo detalhe |
| **Flux.1** | Usar os mesmos prompts, mas adicionar "ultra photorealistic, 8K, shot on medium format" para melhor resultado |
